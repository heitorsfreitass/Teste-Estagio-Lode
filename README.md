# Teste Técnico - Estágio em Dev (Lode)

Projeto desenvolvido para o teste.

## Tecnologias

- Java + Swing
- Vue.js v3.5
- Bootstrap
- Git

## 1. Java

Sistema simples de controle de estoque de peças.

Funcionalidades:
- tabela com peças
- cálculo de valor total
- total geral do estoque
- item de maior valor

## 2. Vue.js

Checklist de manutenção de poço artesiano.

Funcionalidades:
- marcar tarefas como concluídas
- feedback visual
- confirmação ao desmarcar
- progresso em %

## Como rodar

### Java
Abrir o projeto no NetBeans e executar.

### Vue

```bash
cd frontend-vue
npm install
npm run dev
